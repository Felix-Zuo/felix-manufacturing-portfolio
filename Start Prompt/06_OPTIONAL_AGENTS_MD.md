# AGENTS.md

## Project Mission

Build and maintain Felix Zuo's independent manufacturing project improvement portfolio website.

The site should present Felix as a manufacturing project coordination and digital process improvement professional with evidence-backed outcomes, public sanitized portfolio projects, and a clear path from factory workflow problems to measurable improvements.

## Working Context

Felix's strongest positioning:

- Manufacturing project coordination
- Process improvement
- Trial production optimization
- PPAP and delivery readiness
- Material readiness and supply-production-delivery tracking
- Audit support and corrective action closure
- Lean / Six Sigma thinking
- PDCA improvement
- Digital workflow tools as improvement enablers

## Development Principles

- Keep content structured and data-driven.
- Prefer reusable components.
- Keep pages responsive and accessible.
- Maintain a professional industrial visual style.
- Use public links and synthetic-data portfolio projects as evidence.
- Keep confidentiality boundaries visible and professional.
- Run available build, lint, and test checks before marking work complete.

## Content Principles

Use evidence first:

- Metrics
- Case studies
- Before/after workflows
- Public demos
- GitHub links
- Methodology
- Confidentiality boundaries

Avoid bloated keyword stacking. Use natural professional language.

## Confidentiality Principle

Public content should use sanitized or synthetic data and should not expose customer names, private BOMs, supplier records, internal exports, production routes, real machine parameters, or confidential factory files.
