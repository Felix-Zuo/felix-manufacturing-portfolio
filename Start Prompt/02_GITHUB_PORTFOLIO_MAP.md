# GitHub Portfolio Map

## GitHub Profile

Profile: https://github.com/Felix-Zuo

Felix's GitHub is currently positioned around smart manufacturing, industrial AI applications, factory data, and practical AI-assisted workflow automation. The new portfolio website should refine this into a stronger market-facing story:

> Manufacturing project coordination and process improvement, supported by practical digital tools and public synthetic-data showcases.

## Confidentiality Framing

All repository links should be framed as:

> Public sanitized or synthetic-data showcases based on real manufacturing workflow patterns.

The website should never imply that real customer files, real BOMs, real production routes, real machine parameters, supplier records, or ERP exports are public.

## Suggested Portfolio Lab Card Wording

### Factory Takt Simulator

Visual takt-time and flow-simulation workstation for modular discrete-manufacturing lines. Demonstrates process routing, buffer tuning, transfer constraints, bottleneck analysis, and capacity reporting with sanitized synthetic scenarios.

### Structured Operations Notice Workbench

Local-first notice and release workflow demo that turns structured work-package data into Excel notices, browser previews, manifests, and reviewable workflow context.

Spreadsheet operations workbench that classifies files, normalizes noisy headers, computes operational metrics, and exports local dashboards and JSON summaries for reporting workflows.

Privacy-safe BOM and material search foundation for parsing cleaned Excel BOMs, building local SQLite indexes, and preserving source evidence for material traceability.

### Operations Intelligence Platform

Personal concept demo integrating manufacturing and fulfillment data into a local control-tower-style product: BOM readiness, inventory risk, release gates, line simulation, and tool-call traces.

### Six Sigma Study App

Local-first bilingual Six Sigma study platform showing Felix's structured approach to technical learning, Lean/Six Sigma concepts, content workflows, and validation gates.

### HulunGuard

Proof-first reliability guard for long-running agent work, focused on evidence, task drift, unresolved failures, and verification.
