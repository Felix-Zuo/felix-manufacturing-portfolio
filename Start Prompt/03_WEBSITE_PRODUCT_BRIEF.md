# Website Product Brief

## Working Title

Manufacturing Project Coordination & Digital Process Improvement

## Core Promise

Felix turns manufacturing project chaos into measurable execution improvement.

The website should show how repeated manual checks, scattered production data, trial-and-error adjustment, and delivery coordination problems can be turned into structured workflows, measurable improvements, and practical digital tools.

## Homepage Hero

### Main Title

Manufacturing Project Coordination & Digital Process Improvement

### Subtitle

I support overseas automotive bearing manufacturing projects from risk review, DFMEA follow-up, PPAP, trial production, mass production, shipment, and delivery, turning repeated manual checks, scattered production data, and trial-and-error adjustment into structured workflows, measurable improvements, and practical digital tools.

### Metric Cards

1. `20-40 min → <1 min`  
   Production notice preparation time

2. `3 days → 1 day`  
   Trial takt analysis and adjustment cycle

3. `~90% reduction`  
   Trial machining and debugging scrap material

4. `~RMB 20,000 / changeover`  
   Estimated saving for regular model changeover

## Visual Direction

The site should feel like:

- Industrial control room
- Manufacturing project review deck
- Premium consulting case study
- Modern product landing page

Visual ingredients:

- Dark graphite / navy / off-white background
- Steel blue accents
- Amber warning accents
- Green improvement accents
- Metric cards
- Process timelines
- Before/after workflow diagrams
- Case study cards
- System maps
- Screenshots
- Public demo links
- Subtle reveal animations

Avoid visual clutter. The design should be intense because the evidence is intense, not because every element is spinning like a confused fan.

## Confidentiality Note

Place near homepage and portfolio lab:

> This portfolio uses sanitized or synthetic data to demonstrate selected improvement outcomes and tool concepts based on real manufacturing workflow patterns. No customer names, private BOMs, supplier records, internal system exports, production routes, machine parameters, or confidential factory files are disclosed.

## Copywriting Principles

Use clear, precise language.

Prefer:

- "reduced"
- "shortened"
- "standardized"
- "tracked"
- "coordinated"
- "supported"
- "improved visibility"
- "enabled less-experienced users"
- "estimated savings"
- "synthetic-data showcase"

Avoid inflated language.

The website should be confident because the numbers are strong. It does not need cheap hype.
