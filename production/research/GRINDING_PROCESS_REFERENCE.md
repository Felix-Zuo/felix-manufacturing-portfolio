# 外圈沟道湿磨英雄镜头：工艺与 Blender VFX 实施规范

> 状态：可进入资产替换、动画与特效制作  
> 目标版本：Blender 4.5.11 LTS，Cycles 最终渲染  
> 镜头对象：轴承外圈的**内沟道**湿式切入磨削，不是外圆磨削，也不是砂轮沿轴向钻入材料  
> 私密资料边界：用户两张机床实拍图只作为观察依据，不复制、不提交、不在公开资产中暴露原始路径或设备身份。

## 1. 结论先行

英雄镜头必须让观众在不看说明文字时也能读懂以下因果链：

1. 外圈由机械手送入左侧夹具，在支承/定位完成后被可靠吸持或夹紧。
2. 机械手完全退出危险区，工件才开始低速旋转。
3. 右侧高频电主轴带动小直径磨轮高速旋转；磨轮先沿轴向进入外圈孔内，到达沟道平面，再沿沟道法向作径向切入。
4. 乳化液先于接触建立稳定冲刷；磨轮接近工件时，轮周空气层和狭小间隙已经会使射流弯折、铺展和回卷。
5. 粗磨接触后，接触弧附近出现厚液膜、切向甩液、少量短寿命湿火星和向下回流；半精磨、精磨与无进给光磨阶段逐步安静下来。
6. 磨轮先退离沟道，冷却液延迟关闭，工件随后减速；不允许工件悬空旋转、机械手扶着工件磨削，或磨轮穿过夹具。

这条镜头的可信度来自**空间关系、动作顺序和液体响应的一致性**，不是来自堆叠大量火花、雾和镜头抖动。

## 3. 正确空间关系

### 3.1 坐标约定

- `X`：主轴轴线，画面中从右侧磨削主轴指向左侧工件。
- `Z`：竖直方向。
- `Y`：机床前后方向。
- 工件轴与磨轮主轴轴线应近似平行；如果真实机型为成形沟道而存在小角度摆轴，以实际轮廓和主轴姿态为准。
- 磨轮中心位于外圈孔内，并相对工件中心产生径向偏置，使磨轮外圆只接触内沟道的一小段接触弧。

### 3.2 左侧工件与夹持

实拍锁定左侧为工件/夹持区。建模上至少要有：

- 轴承外圈实体，内沟道截面清楚，不得用普通平内孔替代。
- 背靠基准面或电磁吸盘面。
- 两个可读的支承/定位鞋，或与实际设备一致的定心结构。
- 轴向拉紧/推料机构、止挡、气缸或拉杆中的至少一种，且动作顺序清楚。
- 夹具背板、紧固件、密封、导液槽和回流路径。

薄壁轴承环不能为了“看起来有机械感”而换成三爪卡盘随意夹紧。STUDER 的轴承环鞋式磨削资料说明，支承鞋负责保持中心，电磁吸盘提供转矩与保持力，目的之一正是避免薄壁件变形。[STUDER 鞋式磨削官方资料](https://cdn.studer.com/fileadmin/content_live_2019/www.studer.com/01_pdf/02_flyer/englisch/shoe-grinding-flyer_studer_en.pdf)

若后续确认用户机床不是电磁吸持，则保留“支承定位、轴向就位、夹紧确认、机械手退出、再旋转”的动作逻辑，替换具体夹具资产，不得保留错误的电磁结构。

### 3.3 右侧主轴与小磨轮

实拍锁定右侧为电主轴/磨轮区。正确外形应包含：

- 刚性圆柱或阶梯式主轴壳体，不是细杆直接插进方盒。
- 主轴鼻端、外锥/内锥或专用接口、锁紧螺母、磨削杆/接长杆。
- 金属轮芯与独立磨料层；实拍中的绿色小轮应有颗粒尺度微法线，而不是光滑塑料圆盘。
- 迷宫密封或密封气区域、冷却/润滑接口、传感器线缆与保护套。
- 主轴滑台、导轨护罩、刮屑/挡液结构。

GMN 和 FISCHER 的官方产品资料均把小孔内磨与高转速、高刚度、高精度主轴、专用磨削杆接口联系在一起；GMN 还列出轴内供液、转速、振动和声发射传感选项。这些资料应作为主轴轮廓与附件密度的造型基线，而不是继续使用“圆柱 + 圆锥 + 圆片”的占位模型。[GMN 内圆磨主轴](https://www.gmn.de/en/spindles/application-areas/grinding/)；[FISCHER 磨削主轴与内磨结构](https://int.fischerspindle.com/en/products/the-world-of-grinding)

### 3.4 进给方向

动作分为两类，不能混为一次直线穿刺：

1. **轴向定位**：磨轮从右向左进入外圈孔内，到达沟道所在的轴向平面；这一步是避让与定位，不承担主要材料去除。
2. **径向切入**：磨轮头沿内沟道局部法向靠近沟道壁，完成粗磨、半精磨、精磨和无进给光磨；视觉上是小轮“贴入小圈沟道”，不是大砂轮磨外圆，也不是磨轮沿自身轴线钻孔。

如实际机型把两个分量合成为斜向滑台运动，动画仍应满足：接触点法向位移主导材料去除，轮芯、主轴鼻端和工件不得互相穿模。

## 4. 旋转与接触运动

### 4.1 速度量级

磨轮以圆周速度控制，换算公式为：

```text
rpm = 60 * Vs / (pi * D)

Vs: 磨轮圆周速度，m/s
D:  磨轮直径，m
```

生产线研究中的基准为 60 mm 磨轮、38 m/s、工件 250 r/min，对应磨轮约 12,100 r/min。若同样圆周速度使用 40 mm 磨轮，则约为 18,100 r/min。Norton 也明确指出，磨轮规格、主轴功率、轮速和冷却条件必须作为一个系统考虑；高性能陶瓷结合剂 cBN 工艺常采用更高圆周速度，但不能脱离实际轮型与额定速度擅自套用。[Norton 磨轮规格因素](https://www.nortonabrasives.com/en-us/resources/expertise/7-factors-used-determine-grinding-wheel-specification)；[Norton Vit-cBN 工艺要求](https://www.nortonabrasives.com/en-us/resources/expertise/5-reasons-upgrade-vit-cbn)

**动画建议**：

- 工件：先以 `220-260 r/min` 作为视觉代理，最终按真实控制数据修正。
- 磨轮：按实际直径用圆周速度公式计算；没有真实数据时，以 `35-45 m/s` 建立预览，不硬编码一个对所有轮径都错误的 rpm。
- 所有旋转使用线性驱动，不用带缓入缓出的循环关键帧；只有启停段允许受控加速度。

### 4.2 旋向判定

不要在文档里写死“画面顺时针”，因为相机换到主轴另一侧后视觉符号会反转。正确判据是：

- 在内沟道接触点取磨轮和工件的局部切向速度。
- 两个速度应相向，使相对切削速度由两者叠加，而不是接近同向拖擦。
- 对近似平行轴的内圆接触，这通常意味着磨轮与工件的角速度向量相反。
- 若主轴有倾角，以接触点局部速度矢量为准，不能只看全局 Euler 角正负号。

最终交付前应使用实际机床短视频或在安全条件下观察工件标记确认旋向；本镜头不得凭相机视角猜测。

### 4.3 旋转可读性

- 工件表面保留一个极轻的激光刻字、油膜断点或粗糙度差异，使约 250 r/min 的旋转可读。
- 高速磨轮不应看到清晰“辐条逐帧跳动”。磨料层应表现为连续环向运动模糊，轮芯只保留非常弱的非对称标记。
- 液膜和切向甩液是高速旋转的主要证据；不要为了看清转动而把磨轮降到不可信的慢速。
- 24 fps 下若高速旋转混叠，磨轮/液体特效层以 48 或 96 fps 渲染后重定时，不通过错误减速解决。

## 5. 夹紧、进给与周期

### 5.1 必须遵守的联锁叙事

```text
机械手到位
-> 工件贴靠基准
-> 支承/定心闭合
-> 轴向拉紧或电磁吸持建立
-> 机械手松爪并退出
-> 夹紧确认灯/传感器响应
-> 工件旋转
-> 磨轮达到工作速度
-> 冷却液预流
-> 快速接近
-> 粗磨
-> 半精磨
-> 精磨
-> 无进给光磨
-> 磨轮退刀
-> 冷却液延时关闭
-> 工件减速
```

“无进给光磨（spark-out）”是停止继续切入、利用系统弹性释放完成尺寸与表面稳定的阶段，名称不表示此时应该制造更多可见火花。外圈沟道生产线论文的具体实验周期为：粗磨 7.87 s、半精磨 2.00 s、精磨 2.00 s、无进给光磨 1.80 s；影片可压缩时长，但不能改变阶段顺序或把所有阶段做成同一个恒速接触。[外圈沟道多阶段切入磨削研究](https://researchonline.ljmu.ac.uk/id/eprint/3328/1/In-Process%20Monitoring%20and%20Analysis%20of%20Bearing%20Outer%20Race%20Way%20Grinding%20based%20on%20the%20Power%20Signal-9.pdf)

### 5.2 8.5 秒电影化压缩版

| 时间 | 工艺动作 | 速度/进给表达 | VFX 响应 |
| --- | --- | --- | --- |
| 0.00-0.70 s | 工件贴靠、支承与夹紧完成 | 工件不转；磨轮可在远端预转 | 机内只有旧湿痕和滴流，无新飞溅 |
| 0.70-1.30 s | 机械手退出，工件与磨轮升速 | 工件平稳升至代理转速；磨轮先达到稳定高速 | 油膜标记开始循环；无火星 |
| 1.10-1.70 s | 主冷却喷嘴预流 | 泵压快速建立后保持近似稳定 | 连贯射流先出现，打在轮周/沟道入口并开始铺展 |
| 1.30-2.00 s | 轴向进入、径向快速接近 | 尚未发生材料去除 | 空气层使射流轻微偏折；间隙变小时回卷增强 |
| 2.00-4.25 s | 粗磨 | 最高切入率；初始接触允许短暂不稳定 | 厚液膜、强切向甩液；短促湿火星只在接触建立和负载波动时出现 |
| 4.25-5.25 s | 半精磨 | 切入率下降 | 飞溅幅度下降，液流仍连续；火星显著减少 |
| 5.25-6.10 s | 精磨 | 很小切入率 | 接触区稳定，主要看到薄液膜与细雾，几乎无明显火星 |
| 6.10-7.20 s | 无进给光磨 | 径向位置保持，无新增进给 | 火星归零或只剩偶发一两颗；冷却和旋转保持，液膜更均匀 |
| 7.20-7.80 s | 径向退离、轴向退出 | 先脱离接触，再退出孔内 | 甩液快速衰减；喷嘴继续冲洗 0.2-0.4 s |
| 7.80-8.50 s | 冷却关闭、工件减速 | 工件在确认脱离后减速 | 射流断开后只剩重力滴流、壁面下淌和槽内回流 |

所有速度变化用连续 S 曲线；接触瞬间可以有负载引起的微小结构振动，但相机、机床底座和主轴不得像手持工具一样大幅抖动。

## 6. 冷却液的真实视觉规律

### 6.1 从喷嘴到回流的因果链

1. **喷嘴出口**：乳化液以连续、近似相干的扁平射流或圆柱射流离开喷嘴，边缘略有波动，不应一出喷嘴就变成均匀雾。
2. **轮周空气层**：高速磨轮会带动周围空气形成边界层，低动量射流会被偏转，难以进入接触区；因此主喷嘴要靠近并瞄准整个磨削区，速度与压力要足以破开空气层。[轮周气流与冷却射流实验研究](https://www.sciencedirect.com/science/article/pii/S2212827117304444)
3. **接触液膜**：射流在磨轮、沟道和夹具之间被压成不规则薄片，局部短暂遮住真实接触点。
4. **切向携带**：磨轮和工件表面的液膜被局部切向速度带走，在接触出口侧形成主要甩液方向；不应从整个圆周平均向四面八方爆炸。
5. **破碎**：液片边缘拉成短液丝，再断裂为大小不一的液滴；微滴形成近场雾，大滴沿抛物线下落。
6. **碰壁与回流**：大部分液体撞到机内护板、夹具和槽体后失去速度，形成湿斑、下淌和底部回流，不应像弹力球反复弹跳。

Norton 对内圆磨削的建议是确保喷嘴准确覆盖磨削区，并以足够流量和压力排出磨屑；由于孔内空间有限，通常应优先使用洪流式供液，而不是硬塞入面向磨轮的高压清洗喷嘴。[Norton 冷却液投送指南](https://www.nortonabrasives.com/en-us/resources/expertise/5-grinding-considerations-improving-surface-finish)

### 6.2 材质外观

- 基础色以实拍的乳白偏黄绿色为准，建议从 `#C9CBB0` 到 `#AEB59A` 建立脏污和厚度变化。
- 乳化液是散射、浑浊的工作液，不是无色玻璃。近景核心液体使用高漫反射、低至中等透射和厚度吸收；薄液膜可更透明，但不能看到像玻璃管一样清晰的背景折射。
- 喷流核心、液片、液丝、液滴必须有不同的厚度和高光尺度。
- 湿金属的粗糙度降低并出现暗色湿边；干燥区域不能与浸湿区域使用同一材质响应。
- 泵压稳定后，喷流总体流量应稳定；运动感来自沿流向传播的表面扰动、碰撞和破碎，不来自整根射流周期性缩放。

### 6.3 明确禁止“静态透明管”

以下任一情况即判定冷却液失败：

- 喷嘴到接触区是一根轮廓完全不变的透明曲线。
- 纹理只在 UV 上滑动，但液体外轮廓、撞击点和飞溅完全不变。
- 射流穿过磨轮、工件或主轴后仍保持原形。
- 液滴没有初速度方向、重力或碰撞结果，只在空间均匀漂浮。
- 冷却液在未开泵时已经铺满运动路径，或停泵后一帧全部消失。

## 7. 少量湿火花

磨削火花本质上来自被磨粒带出的高温微小金属屑；研究指出，磨屑离开接触区后还会因表面氧化出现亮度峰值。[磨削磨屑热行为原始研究](https://www.sciencedirect.com/science/article/pii/089069559290045I)

湿磨英雄镜头采用**受控可见性**，不是干磨烟花：

- 火花只从真实接触弧的出口侧生成，初速度近似沿磨轮局部切线，并带少量离面散布。
- 粗磨刚建立接触时允许短簇；稳定粗磨时零星出现；半精磨显著减少；精磨和无进给光磨接近归零。
- 24 fps 下单颗可见寿命建议 `2-6 帧`；强亮核心通常不超过 `2 帧`。
- 同一帧建议 `4-18` 条可辨识轨迹，极短峰值不得超过 `30` 条；至少一半被液膜、零件或景深遮挡。
- 轨迹长度以接触区局部尺度为准，通常只跨过画面高度的 `1%-6%`；禁止长距离贯穿机舱。
- 颜色从短暂浅黄白核心过渡到橙红后熄灭；不要使用纯白常亮线、规则分叉和大面积环境照明。
- 与乳化液相交后通过寿命、亮度和长度迅速衰减，表现为“被压暗”，无需昂贵的热流体耦合。

这部分属于 D 级影视夸张：真实实拍中大量乳化液可能遮蔽绝大多数火星。最终效果应以“观众能在两三次短簇中确认正在去除金属”为上限。

工艺对象、流体核心、粒子、雾和火花必须可单独关闭、单独采样和单独渲染，便于成本控制与合成修正。

### 8.2 L0：真实几何层

优先把计算预算花在会形成剪影、遮挡和反射的实体上：

- 外圈沟道真实截面、磨轮磨料层、轮芯、磨削杆和主轴鼻端。
- 支承鞋、吸盘/夹具背板、推料或拉料机构。
- 喷嘴出口、金属管、软管接头、阀体和固定夹。
- 主轴滑台、护罩、刮水片、紧固件、壁板接缝和底部回流槽。

小于最终像素的螺纹和磨粒使用法线/粗糙度贴图；会被液体打亮的边缘、喷嘴唇口和主轴接口必须保留真实倒角。

### 8.3 L1：主射流曲线几何

- 每个主喷嘴使用一条中心曲线和 `2-3` 条边缘扰动曲线，不使用单根完美圆柱。
- 出口截面匹配真实喷嘴：扁嘴用椭圆/扁平轮廓，圆嘴用近圆轮廓。
- 曲线半径沿流向有 `±5%-10%` 的低频变化；撞击前保持连贯，撞击后立即转入液片层。
- 材质中的噪声坐标沿曲线弧长以实际流向移动，同时使用形变或 Geometry Nodes 改变外轮廓，保证连续帧中轮廓也在变化。
- 射流终点绑定到物理撞击面或接触区代理，不允许固定在世界坐标中穿透移动部件。

这一层负责从中远景读出“液体正在流动”，渲染成本远低于全域流体模拟。

### 8.4 L2：撞击液片

- 在磨轮入口、接触弧和夹具回流处分别建立 `2-4` 片低厚度动态网格。
- 液片通过形状键或 Geometry Nodes 在 `4-10 帧` 内改变边缘、卷曲和破孔；边缘透明度可用厚度/噪声驱动，但核心仍有实体感。
- 接触液片的发射点跟随磨轮进给位置；磨轮退刀后，液片应在 `4-8 帧` 内失去支撑并向下坍落。
- 不做完整 Mantaflow 主模拟。英雄镜头的可信度主要来自撞击位置和速度方向，完整自由表面求解会显著增加缓存、调参和渲染成本。

### 8.5 L3：切向液丝与液滴

使用 Geometry Nodes Simulation Zone：

- 液丝：同时存活 `20-48` 条短曲线，半径约 `0.4-1.8 mm`，寿命 `4-12 帧`。
- 近景液滴：同时存活 `300-900` 个实例，粒径 `0.3-2.5 mm`；只在镜头前景保留真实低面数几何。
- 远景液滴：`800-2500` 个点或相机朝向小面片，粒径更小，用于密度而不是单颗高光。
- 初速度分解为：局部切向速度主分量 + 射流冲击分量 + 小幅随机离面分量。
- 每步加入重力、空气阻力和有限碰撞；撞击机壁后大部分粒子删除，并在湿痕/下淌层生成替代响应。
- 使用固定随机种子，Simulation Zone 至少 `2-4` 个 substeps；确认运动后 bake 到磁盘，保证网络/分块渲染可重复。

Blender 4.5 的 Simulation Zone 支持缓存、子步和用于运动模糊的子帧插值，适合这类受控粒子而不必上全流体。[Blender 4.5 Simulation Zone 官方文档](https://docs.blender.org/manual/en/4.5/modeling/geometry_nodes/simulation/simulation_zone.html)

### 8.6 L4：雾、湿痕与回流

- 接触区只放一个局部低密度雾体，包围盒严格限制在磨轮/工件附近；体积步数保持低，不能让整个机舱发白。
- 远离焦点的雾使用 `3-6` 张有深度差的动画卡片或低分辨率 VDB，不使用全机舱高分辨率体积。
- 机壁湿痕通过顶点色/动态遮罩控制粗糙度和暗度；液滴碰撞只需触发预设湿痕增长，不做薄膜流体求解。
- 底槽使用静态液面、局部波纹法线和少量落液激波环；不把整个回收槽做成高分辨率流体域。

### 8.7 L5：湿火花

- Geometry Nodes 生成点，再转为带锥度的短曲线；发射器绑定接触弧出口。
- 发射率由工艺阶段、瞬时进给和接触状态共同控制，未接触时强制为零。
- 使用 `age/lifetime` 驱动长度、发光和颜色；与冷却液深度遮罩相交时缩短寿命。
- 火花层不产生显著全局照明，只允许极弱局部反射；主要亮度在合成中由 Emission pass 控制。
- 保留固定随机种子与阶段性脉冲，避免每次渲染火花位置变化导致无法审片。

### 8.8 高速旋转与运动模糊

旋转驱动采用：

```text
rotation_rad(frame) = 2 * pi * rpm / 60 * frame / fps
```

- F-Curve 必须线性，不允许每圈重复关键帧产生速度接缝。
- Cycles 运动模糊 shutter 建议从 `0.35-0.50` 测试；工件标记应仍可读，磨轮磨料环应成为连续环向模糊。
- 高速轮的真实角速度可能在相邻帧跨越多圈。若出现反转/冻结混叠，磨轮、液体和火花单独以 48/96 fps 渲染后按时间重采样；不要降低物理圆周速度。
- 磨料层可叠加非重复环向微纹理增强模糊稳定性，但不能用材质滚动替代整个轮体旋转。

### 8.9 材质与灯光

- 磨料层：绿色/青绿色结合剂、细颗粒微法线、较高粗糙度；轮芯为湿润钢材，二者边界清楚。
- 机内金属：拉丝、磨痕、局部冷却液污渍与边缘油膜，不做均匀镜面铬。
- 软管：橡胶粗糙度、压接套和弯曲半径真实，不能悬空直插。
- 主灯模拟机床内部 LED；接触区可加一盏受控软补光，但不得出现无来源的蓝橙霓虹。
- 至少保留一个暗面，让乳化液高光、磨轮轮廓和少量火花在深色背景上可读。

### 8.10 View Layer 与合成

建议拆分：

1. `VL_SOLIDS`：机床、工件、主轴、机器人。
2. `VL_COOLANT_CORE`：射流与液片。
3. `VL_PARTICLES`：液丝与液滴。
4. `VL_MIST`：局部雾和回流氛围。
5. `VL_SPARKS`：湿火花。

输出 `Combined`、`Z`、`Vector`、`Emission`、`Mist` 和 Cryptomatte。Beauty 层正常降噪；细液滴和火花先检查未降噪结果，避免去噪器把短寿命细节吃掉。Cycles 对高光、透射和体积容易产生噪点，官方也建议通过限制高能亮点、优化光路和合理降噪控制动画成本。[Blender Cycles 降噪与噪点控制](https://docs.blender.org/manual/en/4.5/render/cycles/optimizations/reducing_noise.html)

## 9. 英雄镜头运镜

### 9.1 镜头目标

一个方向明确的 `8.5 s` 连续镜头完成“外部装料 -> 进入机床 -> 夹紧旋转 -> 湿磨爆发 -> 安静光磨 -> 退刀”的小故事。相机不在两个显示屏之间来回摇，也不靠频繁切镜制造速度。

### 9.2 分镜

| 时间 | 相机 | 画面重点 | 叙事目的 |
| --- | --- | --- | --- |
| 0.00-0.80 s | 32-35 mm，从机门外沿机械手和外圈运动方向前推 | 机械手将外圈贴到左侧夹具；右侧主轴在深处形成视觉终点 | 建立“这一个工件将被加工”的主角 |
| 0.80-1.45 s | 穿过尚未关闭的机门；借门框/软管作前景遮挡 | 夹紧机构动作，机械手松爪退出 | 用真实遮挡完成外到内的空间转换，不穿墙 |
| 1.45-2.20 s | 45-55 mm，低角度沿主轴轴线前移并向接触侧偏航不超过 15° | 工件起转、磨轮高速、乳化液预流 | 让左右空间关系和速度差一眼可读 |
| 2.20-4.30 s | 55-65 mm，单向绕接触区小弧线前移 | 径向切入、粗磨、液片与两三次短簇湿火花 | 全片张力峰值；相机仍稳定，不模拟手持震动 |
| 4.30-5.80 s | 65-75 mm，运动速度降低到前段约 60% | 半精磨/精磨，液体规律变得更稳定 | 从爆发转向精密控制，形成节奏变化 |
| 5.80-6.80 s | 75-90 mm 微距；用 96 fps 特效层重定时到约 35%-45% | 6-12 颗可辨液滴和极少火花掠过镜头，沟道表面在液膜间歇露出 | 子弹时间只服务于“看清物理”，不是全场冻结 |
| 6.80-7.35 s | 相机恢复正常速度，轻微后撤 | 无进给光磨，火花消失、液膜稳定 | 告诉观众工艺进入完成态 |
| 7.35-8.50 s | 磨轮退刀；相机借主轴护罩或门边完成向下一节点的遮挡 | 冷却液延时关闭、回流、工件减速 | 给下一项目卡片或场景转场留下自然遮挡 |

### 9.3 卡片触发原则

- 粗磨张力峰值期间不弹大卡片，避免遮挡接触关系。
- 项目卡片只允许在 `6.80-7.35 s` 的稳定光磨或 `7.35 s` 以后退刀阶段出现。
- 卡片从机床 HMI 边缘、门框负空间或稳定的画面边缘生长，使用屏幕空间跟踪；不要像实体牌子一样漂在冷却液里。
- 一次只出现一张主要卡片，最大占画面 `28%-34%`，并保留工件、磨轮和接触区至少两个可见锚点。
- 卡片出现不改变工艺运动；工件、液体、回流和背景机构必须继续运行。

## 10. 渲染成本控制

### 10.1 预览与最终档

| 阶段 | 分辨率/采样 | 用途 | 不可用于 |
| --- | --- | --- | --- |
| Layout | 960x540，16-32 samples | 机位、穿模、节奏、构图 | 判断材质、液体清晰度和最终噪点 |
| FX review | 960x540，64-96 samples | 连续 48 帧检查射流、液滴、火花和运动模糊 | 对外发布 |
| Final | 1920x1080，128-192 samples 起步，adaptive sampling + OIDN | 网站桌面视频母版 | 用单帧好看替代时序验收 |

GPU 支持时使用 OptiX；Blender 4.5 官方文档确认 Windows/Linux 上可用 OptiX GPU 渲染，并支持 RTX 上的 GPU 加速降噪。[Blender 4.5 GPU 渲染](https://docs.blender.org/manual/en/4.5/render/cycles/gpu_rendering.html)

### 10.2 明确不做

- 不做全机床 Mantaflow 高分辨率域。
- 不为远景液滴建高细分球体。
- 不让火花参与高强度间接照明。
- 不在玻璃、冷却液和湿金属上同时开启昂贵焦散。
- 不在 layout 预览中用 4 samples 的点阵噪声判断最终质量。

## 11. 镜头级验收标准

### 11.1 工艺正确性

- [ ] 外圈在左，小磨轮与主轴在右；磨轮进入的是外圈内沟道。
- [ ] 轴向进入只负责到位，材料去除由沟道法向的径向切入体现。
- [ ] 工件夹紧、机械手退出后才旋转；磨削期间机械手不接触工件。
- [ ] 工件与磨轮局部接触速度相向；不存在两者同速拖行的视觉。
- [ ] 粗磨、半精磨、精磨、无进给光磨、退刀顺序完整。
- [ ] 所有主轴、磨轮、夹具、喷嘴和护罩无穿模。

### 11.2 冷却液

- [ ] 能逐帧读出“喷流 -> 液片 -> 液丝 -> 液滴/雾 -> 回流”。
- [ ] 撞击点随磨轮进给变化，甩液主要沿局部切线并受重力下落。
- [ ] 乳化液浑浊、有厚度，不像透明玻璃或发光能量束。
- [ ] 接触前有空气层/狭缝引起的偏折，接触后飞溅增强，退刀后衰减。
- [ ] 停泵后有尾流、滴落和壁面下淌，不是一帧清空。

### 11.3 火花

- [ ] 未接触时为零；粗磨接触建立时最明显；精磨和光磨接近归零。
- [ ] 单帧主要火花不超过 18 条，峰值不超过 30 条。
- [ ] 轨迹短、沿接触出口切线、被乳化液快速压暗。
- [ ] 没有长尾烟花、规则分叉、360° 发射或照亮整个机舱。

### 11.4 运镜与画面

- [ ] 相机从开放机门进入，或通过真实前景遮挡完成隐藏转场；不穿过实体门板。
- [ ] 主运动方向单一，粗磨后继续向前/侧弧，不在显示屏之间往返摇摆。
- [ ] 子弹时间仍保留工件旋转、磨轮模糊、液滴惯性和背景动作。
- [ ] 关键接触区至少连续可读 2 秒；液体可以间歇遮挡，但不能始终完全盖住工艺。
- [ ] 卡片只在稳定/退刀阶段出现，不遮住全部接触关系。

### 11.5 时序与最终质量

- [ ] 连续抽查至少 48 帧，无磨轮反转、液滴跳位、随机种子变化、体积闪烁或去噪拖影。
- [ ] 1920x1080 最终母版在 100% 查看时，主轴轮廓、沟道、磨料层、喷嘴唇口和夹紧机构可辨。
- [ ] 暗部无大面积点阵噪声；湿高光不产生随机白点；火花未被去噪器吞掉。
- [ ] 至少检查阶段边界前后各 6 帧，所有速度、流量和发射率连续。

## 12. 典型失败示例

| 失败画面 | 为什么错误 | 修正 |
| --- | --- | --- |
| 大砂轮从外侧压在轴承大圈外圆上 | 把外圈沟道磨削误做成外圆磨削 | 小磨轮进入孔内，在内沟道局部径向接触 |
| 磨轮沿主轴方向直钻沟道 | 把轴向到位误当成材料去除进给 | 先轴向进入沟道平面，再沿局部法向径向切入 |
| 工件悬空自转或机器人一直抓着磨 | 缺少夹紧、支承与安全联锁 | 明确支承/吸持、松爪、退出、确认后才旋转 |
| 绿色磨轮是光滑塑料圆片 | 缺少磨料层、轮芯和主轴接口 | 分离磨料环与金属轮芯，增加颗粒微法线与锁紧结构 |
| 冷却液是一根静态透明软管 | 没有流速、撞击、破碎和回流 | 使用曲线核心、动态液片、切向液丝、粒子和湿痕分层 |
| 液体从接触点 360° 均匀爆炸 | 忽略轮周速度和喷嘴动量 | 以接触出口切线为主方向，叠加有限离面散布和重力 |
| 湿磨持续喷出大量长火花 | 接近干式角磨机视觉，不符合洪流冷却 | 粗磨短簇、低数量、短寿命，精磨/光磨接近归零 |
| 无进给光磨阶段火花最多 | 误解 spark-out 名称 | 该阶段无新增进给，视觉应更稳定、更安静 |
| 磨轮每帧倒转或停住 | 高 rpm 在低帧率下发生时间混叠 | 高频特效层提高时间采样后重定时，不降低真实速度 |
| 相机直接穿过关闭的机门和主轴 | 空间连续性失效 | 在门关闭前进入，或用门框/软管/护罩完成隐藏遮挡 |
| 所有表面同样干净、同样粗糙 | 没有机床使用痕迹和湿润层次 | 区分干区、湿区、冲刷区、回流区和底槽积液 |

## 13. 实施顺序

1. 用灰模通过空间关系：外圈、沟道、夹具、主轴、磨轮、喷嘴、滑台。
2. 完成夹紧、退出、旋转、轴向进入、径向切入、阶段进给和退刀。
3. 只加主射流与撞击液片，确认撞击位置和切向方向。
4. 加液丝、液滴、回流和湿痕，完成固定种子缓存。
5. 最后加少量湿火花与局部雾，不用它们掩盖几何错误。
6. 完成 48 帧 FX review，通过后再做材质、灯光、卡片与最终采样。
7. 以本文第 11 节逐项验收，任何工艺硬错误优先于“画面是否更炸裂”。
