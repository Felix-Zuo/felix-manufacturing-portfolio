# V5 混合式电影个人站完整制片计划

## 1. 项目目标

把 Felix Zuo 的制造业作品集做成全屏、电影化、可交互的个人独立站。滚动行为只负责控制镜头和时间线，观众看到的是持续向前的工厂旅程，而不是普通网页模块不断向下移动。

最终体验必须同时具备：

- 明亮、整洁且物理关系可信的轴承生产环境。
- 长运镜、稳定推轨、升格和子弹时间。
- 正确的六轴机械臂、AGV、安全围栏、机床和沟道磨削逻辑。
- 镜头到达关键显示器后，项目界面清晰放大并可真实操作。
- 连续、按比例的滚动控制，不自动跳章节。
- 桌面端、移动端、键盘、减少动态和低带宽回退方案。
- 只使用公开安全的合成数据。

当前线上 V4 在 V5 通过全部发布门禁前保持不变。

## 2. 完成定义

只有同时满足以下条件，V5 才算完成：

1. 工厂影片没有明显形变、穿模、错误工艺、不明物体、平台水印或断裂转场。
2. 普通区域一次约 80 px 的滚轮输入只推进约 0.15 至 0.25 秒影片。
3. 正常滚轮和触摸输入结束后不会自动吸附到章节。
4. 通知、节拍和运营可视化三个核心节点能打开大尺寸、可读、真实的网页界面。
5. 节拍节点运行真实仿真，而不是静态截图。
6. 其余公开项目集中在一个“连接系统”节点中，不在工厂里堆放大量卡片。
7. 桌面、移动、减少动态、键盘和海报回退路径都可用。
8. Lint、生产构建、浏览器检查、媒体检查和 Vercel 预览全部通过。
9. V5 先在预览地址验收，再替换生产首页。

## 3. 不可改变的视觉方向

采用 V4 审核后生成并获用户确认的“工厂控制主轴”修订母版作为唯一视觉基准。

必须保留：

- 中央消失点和完全畅通的服务通道。
- 自然天窗光、真实吊顶桁架和有秩序的管线。
- 位于围栏单元内部的机械臂。
- 位于交通通道外侧凹位的大型节拍屏。
- 石墨、铝、少量安全黄、绿色和琥珀色。
- 小尺寸、低调的 `Felix Zuo` 标识。

必须纠正或删除：

- 凸起轨道和横跨 AGV 通道的结构。
- 机械臂扫掠范围进入通道。
- 没有安装逻辑的悬浮屏幕和卡片。
- 巨型外露砂轮和含糊的轴承加工动作。
- 大量火花、过度雾化、暗黑科幻调色和装饰堆积。
- 由视频模型直接生成的项目 UI 文字。

每个实体镜头只允许一个主视觉对象和一个辅助证据层。

## 4. 总体制作架构

V5 由四个同步层组成。

### 4.1 运动骨架层

Blender 和有明确许可的公共素材只用于：

- 厂房尺度与空间布局。
- 摄影机路径、焦段、朝向和速度。
- 机械臂与 AGV 的安全包络。
- 砂轮、工件和接触点的工艺几何。
- 遮挡检查和移动端安全构图。
- 提供给视频模型的低模运动参考。

低模视频不作为网站最终画面。

### 4.2 生成影片层

整条影片拆成经过审核的 5 秒片段。只有同一镜头的 5 秒测试通过后，才允许生成 10 秒版本。

- Seedance 2.0 是多模态参考和连续性的首选候选。
- Runway Gen-4 Turbo 用于低成本对比和运镜迭代。
- 只有当前账户确实可用且可导出无阻断水印时，才使用 Runway Gen-4.5。
- 每个片段必须有首帧、目标尾帧、一个摄影机动作和一个主体动作。
- 隐藏剪辑放在围栏立柱、机床框架、暗屏、前景运动模糊或显示器全屏时刻。

制作上是多个可控片段，观看上必须像一条连续的一镜到底。

### 4.3 真实项目界面层

项目文字和仪表盘绝不交给视频模型生成。

- 影片里的显示器只保留暗色玻璃、简洁跟踪框或中性屏幕。
- 镜头逐渐正对显示器时，带透视的 DOM 层叠加到物理屏幕上。
- 到达停留帧后，DOM 扩展为大尺寸可交互项目界面。
- 退出项目时反向收回，再继续影片。
- 优先使用同源页面。只有通过 iframe、CSP 和运行检查后才使用公开网址嵌入。

### 4.4 滚动时间线层

首页采用全屏粘性舞台和较长的原生滚动轨道。

- 保留浏览器原生滚动，兼顾触摸、键盘和可访问性。
- 屏幕视觉上保持固定，滚动进度只驱动影片时间和 DOM 动画。
- 分段时间映射负责正常推进、减速、停留和重新加速。
- 不设置滚轮结束后自动跳章节的定时器。
- 键盘方向键按小时间步推进，另外保留明确的章节导航。
- `prefers-reduced-motion` 使用审核过的静帧和直接项目导航。

## 5. 主旅程和交互节点

目标影片长度为 30 秒，不包含用户在交互项目中的停留时间。

| 片段 | 影片时间 | 实体主角 | 摄影机动作 | 网页节点 | 首选生成器 |
| --- | ---: | --- | --- | --- | --- |
| S01 进入 | 0-5 s | 生产主轴、AGV、自然光厂房纵深 | 稳定慢速向前，无横摇 | 只显示身份和成果简层 | Seedance 与 Runway A/B |
| S02 精密单元 | 5-10 s | 围栏内六轴机械臂、封闭磨床 | 继续向前，轻微左侧揭示，短升格 | 不展开项目 UI | Seedance 优先 |
| S03 通知交接 | 10-15 s | 侧置工业 HMI | 越过立柱后正对显示器并减速 | Structured Operations Notice Workbench | A/B 胜出模型 |
| S04 可视化交接 | 15-20 s | 回到通道，第二块凹位运营屏 | 屏幕匹配转场，短横向漂移 | Factory Excel Ops Dashboard 与 Operations Intelligence Platform | Seedance 优先 |
| S05 节拍终点 | 20-25 s | 控制主轴末端大型节拍屏 | 缓慢推近到完全正面 | 真实 Factory Takt Simulator | 可用的最高质量模型 |
| S06 连接系统 | 25-30 s | 检验门和安静的最终厂房画面 | 平滑收速但不急停 | Data Pocket Lab、Six Sigma、HulunGuard、GitHub、联系 | 复用合格转场并合成 |

### 5.1 沟道磨削工艺合同

画面采用外圈竖直装夹、工件轴线水平的方案。小直径轮廓内圆砂轮进入内孔并接触内沟道。

镜头必须明确显示：

- 完整机床防护和观察窗。
- 可信的工件装夹。
- 小直径内圆砂轮，而不是大尺寸端面砂轮。
- 接触点在沟道，不在端面或任意外圆位置。
- 冷却液、微雾和克制的接触亮点，不出现焊接式火花瀑布。

只要违反以上任一条，即使画面漂亮也直接淘汰。

正式生成前先在账户中读取剩余额度。当前没有可见数字时，按比例管理：

| 分配 | 比例 | 用途 |
| --- | ---: | --- |
| 校准 | 15% | 相同首帧的 5 秒运镜测试和提示词校准 |

| 移动端与回退 | 10% | 桌面通过后才制作一至两个 9:16 关键版本 |

场景未稳定前固定使用 5 秒。10 秒只用于简单慢推或已经通过的续拍，不能在一个提示词中安排多个复杂动作。

### 6.3 模型选择规则

每个片段执行同一流程：

1. Seedance 和 Runway Turbo 使用同一首帧及等价运镜指令。
2. 按同一质量表盲评。
3. 每个片段单独选择更好的模型，不强制整条影片使用同一模型。
4. 淘汰片只在仍有可复用运动参考时保留。
5. 构图或提示词尚未锁定时，不消耗高质量生成额度。

## 7. 视频生成协议

### 7.1 每次生成前必须具备

- 审核通过的首帧。
- 明确的尾帧构图目标。
- 摄影机方向、焦段感觉和相对速度。
- 一个主要运动主体。
- 必须保持静止的对象列表。
- 碰撞和工艺说明。
- 可用于隐藏剪辑的位置。
- 移动端安全区域检查。

### 7.2 提示词纪律

提示词主要描述运动，不重复描述首帧已有的全部物体。

推荐结构：

```text
摄影机沿完全畅通的服务通道进行缓慢、稳定的向前推轨。
AGV 以恒定低速前进。围栏内机械臂只完成一次受控的取放动作。
机械臂始终留在安全单元内部，吊顶自然光和机床结构保持稳定。
工业纪录片摄影，克制的运动模糊，无横摇，无镜头滚转。
```

禁止：

- 在 5 秒镜头中安排多个摄影机动作。
- 要求模型生成可读的仪表盘文字。
- 要求首帧中不存在的新设备和装饰。
- 只写“更震撼、更史诗”而没有物理运动说明。
- 大量火花、强烈手持抖动或无约束绕拍。

### 7.3 失败分类与重试

- `GEO`：几何变形、设备复制或结构变化。
- `PROC`：制造工艺错误。
- `COLL`：穿模、通道阻塞或安全包络越界。
- `CAM`：镜头跳动、速度突变、滚转或失焦。
- `LIGHT`：灯光和材质不连续。
- `SEAM`：尾帧无法接续下一片段。
- `UI`：文字、屏幕或叠层损坏。
- `MARK`：水印或 AI 标识阻断发布。

一次重试只修改一个提示词或输入变量。同一类别连续失败三次后，停止重复生成，改首帧或重新设计隐藏剪辑点。

## 8. 镜头评分表

每项 0、1、2 分。片段至少达到 16/20 且没有关键失败才能通过。

| 类别 | 通过标准 |
| --- | --- |
| 厂房几何 | 机床、围栏、通道、HMI 和吊顶保持稳定 |
| 机械臂结构 | 六轴链、腕部和末端工具可信 |
| 工艺逻辑 | 沟道磨削、装夹和防护正确 |
| 交通安全 | AGV 通道畅通，机械臂不越出围栏 |
| 摄影机 | 运镜平滑、方向明确、适合滚动逐帧播放 |
| 连续性 | 首尾帧能与相邻片段连接 |
| 灯光材质 | 自然光和表面质感保持一致 |
| 视觉层级 | 主体唯一，视觉引导线明确 |
| 发布安全 | 无客户信息、品牌误用、水印或私有素材 |
| 网页衔接 | 屏幕角度和停留帧支持 DOM 接管 |

`PROC`、`COLL`、不可修复的 `GEO` 和正式片中的 `MARK` 均为直接淘汰项。

## 9. 网页工程计划

### 9.1 新组件边界

```text
src/components/cinematic-v5/
  CinematicJourneyV5.tsx
  FilmLayer.tsx
  JourneyHUD.tsx
  CheckpointPortal.tsx
  ProjectStage.tsx
  useFilmTimeline.ts
  cinematicJourney.module.css
src/data/cinematicJourney.ts
```

旧 `RenderedJourney` 保留到正式发布完成，作为即时回滚方案。

### 9.2 预览路由

V5 首先建设在 `/cinematic-preview`：

- 生产 `/` 继续使用 V4。
- 在预览路由完成媒体、滚动和交互验证。
- 先部署 Vercel Preview。
- 发布检查通过后才把首页切换到 V5。

### 9.3 时间线行为

- 影片进度来自约 14,000 至 18,000 px 的原生滚动轨道。
- 舞台使用 `position: sticky` 并始终占满视口。
- 分段时间映射在项目节点附近分配更多滚动距离。
- 普通区域目标为每 80 px 推进 0.15 至 0.25 秒。
- 慢速区域目标为每 80 px 推进 0.03 至 0.08 秒，但摄影机不完全静止。
- 不设置滚轮结束后调用章节选择的定时器。
- 影片 seek、DOM 叠层、进度、光标反馈使用同一个标准化进度值。

### 9.4 交互节点

三个主要节点：

1. Notice Workbench。
2. Operations Visibility。
3. Factory Takt Simulator。

节点行为：

- 摄影机先到达显示器正面。
- 影片进入编排好的近静止区间。
- DOM 项目层获得鼠标事件。
- 展开后提供清晰关闭按钮，`Escape` 返回旅程。
- 交互层关闭后，滚动继续推进且不跳章节。
- 只有在完整项目界面展开时才限制键盘焦点。

其余公开项目放在一个克制的标签页界面中，不做成大量实体卡片散落在厂房里。

## 10. 合成与网页媒体编码

### 10.1 母版合成

- 合格片段先进入无损中间时间线。
- 只在必要时使用隐藏剪辑、短光流融合和匹配剪辑。
- 画面锁定后统一做调色、颗粒和环境声音。
- 所有接缝保持摄影机方向和地平线一致。
- 速度变化写入成片，不根据用户滚轮速度临时修改镜头运动。

### 10.2 网页交付媒体

桌面端目标：

- 1920x1080 或不虚构细节的最高真实源分辨率。
- H.264 MP4，启用 `faststart`，使用短而固定的 GOP 以提高 seek 响应。
- 在画质允许时控制在 18 MB 以内。

移动端目标：

- 额度允许时制作专用 9:16 构图，否则使用审核过的中央安全裁切加全屏 DOM 节点。
- 控制在 12 MB 以内。
- 桌面端画面外的对象不能承担关键导航和理解信息。

回退：

- 首屏 WebP 或 AVIF 海报尽量低于 250 KB。
- 减少动态模式使用章节静帧。
- 视频失败时显示海报和直接项目入口。

## 11. 隐私、权利与水印门禁

- 只上传生成的厂房概念图和公开安全项目素材。
- 不上传客户文件、真实工艺参数、私有源码或内部导出。
- 平台允许时保持生成会话为私密。
- 正式发布前确认输出和商业使用条款。
- 不通过删除、遮盖或裁切平台水印规避套餐限制。
- Runway 免费输出在证明无水印且当前账户条款允许前，只视为测试素材。
- 豆包条款允许添加可见或元数据 AI 标识，首个下载样片必须检查后才能判定是否可用于正式网站。

## 12. 六道质量门禁

### Gate A：关键帧

- 构图、工艺、安全间隙和移动裁切全部通过。

### Gate B：5 秒 A/B

- 同一首帧分别测试 Seedance 与 Runway Turbo。
- 胜出片至少 16/20。
- 记录导出、水印和使用权状态。

### Gate C：片段锁定

- S01 至 S05 逐段通过。
- S06 使用合格素材与 DOM 合成。
- 检查每个片段第一帧和最后一帧。

### Gate D：影片锁定

- 全程没有明显接缝、倒车、几何跳变或声音断裂。
- 独立视觉审查无阻断或重大问题。
- 制造工艺审查通过机械臂、AGV、防护和磨削逻辑。

### Gate E：网页预览

- 桌面和移动端连续滚动正确。
- 所有项目节点清晰可操作。
- 节拍仿真实际运行。
- 无横向溢出、水合警告、控制台错误和焦点锁死。

### Gate F：发布

- `npm run lint` 通过。
- `npm run build` 通过。
- 桌面、移动、键盘和减少动态测试通过。
- Vercel Preview 验收通过。
- 首页切换可通过一个提交恢复到 V4。

## 13. 本次任务内的执行顺序

1. 开启 ChatGPT Chrome Extension 的文件网址访问权限。
2. 把获批母版复制进项目制片目录，制作无导航、无假 UI 的干净视频首帧。
3. 用 Seedance 2.0 生成 S01 的 5 秒样片。
4. 用 Runway Turbo 消耗 25 积分生成等价 S01 样片。
5. 下载并按同一标准评分，确认水印和导出条件。
6. 逐镜头选择生产模型并锁定运镜提示词。
7. 逐段生成、审核 S02 至 S05。
8. 合成 30 秒母版，制作海报和移动端媒体。
9. 实现 `/cinematic-preview` 的连续滚动和真实项目节点。
10. 检查公开项目是否允许嵌入；必要时制作同源交互回退界面。
11. 完成媒体、浏览器、可访问性、Lint 和构建检查。
12. 部署 Vercel Preview。
13. 最终预览验收后将 V5 提升为 `/`。
14. 提交并推送正式版本，同时保留 V4 回滚历史。

## 14. 只需要用户介入的节点

1. 开启 ChatGPT Chrome Extension 的 `Allow access to file URLs`。
2. 处理 Runway 或豆包出现的登录、验证码、权限或平台确认。
3. 只有全部免费输出都无法通过发布门禁时，决定是否采用平台提供的无水印付费导出。
4. 在生产首页替换前确认最终 Vercel 预览。

只要平台没有阻断，其余提示词、文件准备、生成登记、下载、评分、合成、前端实现、测试、Git 和部署工作均由 Codex 连续完成。
