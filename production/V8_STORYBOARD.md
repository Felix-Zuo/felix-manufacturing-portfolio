# V8 Storyboard - 一只轴承外圈的旅程

## 1. 影片定位

V8 不再把工厂当成项目卡片的背景，也不再沿通道依次停靠多块显示屏。整片只讲一件事：同一只汽车轴承外圈 `RING_HERO_01` 从入线、识别、取料、装夹、湿磨、检测到出料的完整旅程。三个项目、Felix 的个人身份和改善指标只在工艺事件产生信息的瞬间出现。

观众通过滚动控制时间，而不是向下浏览普通网页。每次滚轮只推进少量画面；连续滚动形成稳定长运镜；到关键证据点时出现轻磁吸。正常自动播放模式不执行磁吸，摄影机从 F001 到 F912 始终保持同一镜头、同一方向和连续速度。

核心观感：

- 一镜到底，但不是匀速巡航。摄影机跟随物料改变高度、横向位置和焦段，film travel 始终单调向前。
- 物料是视觉引导线。任何一次视线转移都由 AGV、机械臂、外圈、冷却液、检测光或出料动作接力，不做无缘由甩头。
- 只让 `Factory Takt Simulator` 真正从 HMI 屏幕展开。通知工作台来自扫码放行，Excel 运营看板来自终检数据，不重复“看屏幕”。
- 工厂动作持续存在，但每个景深层只保留一个主事件。顶置搬运、管线、状态灯和远处设备提供生命感，不与英雄外圈争夺注意力。
- 最后一道门打开后进入真实黑场，再由网页接管为正常全屏汇总页。全程禁止白闪、假切镜和亮色全屏转场。

统一 authoring 坐标采用 `(X, Y, Z)`：

- `+Y` 为产线前进和故事时间方向。
- `+X` 为通道右侧，磨床位于右侧。
- `+Z` 为高度。
- 摄影机路径在所有采样点都满足 `dY/dt > 0`，不得倒车。
- 相机横滚常态小于 1 度，动作转接峰值不超过 2 度；所有项目证据点回到水平。
- 相机朝向变化使用阻尼四元数或 Sequencer Look-at 混合，角速度上限 32 度/秒，禁止左右反复寻找目标。

## 4. 主物料与物理连续性

全片只使用一个英雄物料对象 `RING_HERO_01`。外圈的内沟道、端面、追溯点刻和一处低对比识别标记从开场到终检必须保持一致，不能在不同工位换成比例不同的模型。

父级/约束接力顺序：

`AGV_07.PalletLocator -> ROBOT.GripperLocator -> GRINDER.WorkheadLocator -> OUTFEED.GripperLocator -> INSPECTION.RollerLocator -> AGV_07.OutputLocator`

每次交接必须遵守：

- 切换父级前先匹配世界变换，交接帧前后位置、旋转和尺度连续。
- 同一时刻只有一个主约束权重为 1；接触阶段允许 3-5 帧权重交叉，但不得产生双重位移。
- 夹爪先接触再承重，原托具后释放；出料时同样先夹紧再松开工件主轴。
- AGV 最高速度 1.2 m/s，舒适加速度不高于 0.65 m/s²，减速姿态有轻微悬挂压缩；车轮角速度严格由线速度和轮半径计算。
- 机器人采用关节空间平滑轨迹和 TCP 速度限制。任何轴不瞬停、不反向抽动，电缆包、拖链和软管必须随关节运动。
- 外圈装夹轴线、工件主轴轴线和砂轮主轴轴线均为水平轴线；砂轮进入内孔后再做径向进给，禁止用垂直砂轮磨外圈大圆。
- 湿磨结束后外圈保留真实湿膜、滴液和高光变化；只有经过气刀后接触区域才趋于干燥，不能瞬间变成干件。

## 6. 逐镜实施

### 01 - 跟随 AGV，认识这只外圈

**时间**：F001-F084，0.000-3.500 s  
**速度曲线**：1.35 m/s 起步，1.75 s 前平滑升至 1.65 m/s，末段回落到 1.10 m/s；首帧已有非零速度。  
**焦点**：动态目标 `RING_HERO_01.Center`，焦点距离跟随外圈；f/4.0，背景保留厂房层次。

- F001 从 AGV 后方 1.8 m、离地 0.58 m 开始。两条地面导向线和车轮运动把视线汇聚到竖直固定在托具上的外圈。
- AGV 以稳定速度进入明亮整洁的产线。近处车轮、悬挂、反光标识有视差，远处机器人和磨床仅作为轮廓，不提前抢戏。
- F025-F076，外圈追溯点旁伸出一条 1 px 深度跟踪线，Felix 身份卡从 AGV 的小型电子铭牌位置展开。卡片内容为 `Felix Zuo`、`Manufacturing Project Coordination & Digital Process Improvement` 和一句核心承诺；不出现巨大黄色姓名。
- 身份卡只做 7 度透视转正、12 px 纵向升起和 0.92 -> 1.02 -> 1.00 的一次轻微升格回弹。它不是磁吸点，摄像机不停、AGV 不减速。
- F070 后卡片收为铭牌旁的细线标签，留下一个可交互热点，视觉注意力回到即将到来的扫描门。
- 声画：低频厂房底噪、AGV 电机和轮胎细响；音乐仅有每两拍一次的低脉冲。卡片展开用短促继电器音，不使用科幻上升音。
- 首尾衔接：F001 的外圈刻痕必须与 F799 后成品上的同一刻痕相符，构成完整闭环。

### 02 - 扫描、校验、放行

**时间**：F085-F150，3.500-6.250 s  
**速度曲线**：1.10 -> 0.58 -> 0.76 m/s，摄影机只缓行，不锁死；横向位移采用单向左移。  
**焦点**：外圈中心与扫码器之间按 70/30 混合；46 mm，f/5.6。

- AGV 在扫描门前按 S 曲线减速，导向销与托具完成机械定位。扫描器先亮定位线，再完成一次从上到下的读码，不反复扫动。
- 工控盒依次显示 `ID captured -> route verified -> released`。绿色放行灯只能在校验完成后亮起，AGV 随后重新起步。
- `Structured Operations Notice Workbench` 不从显示器飞出。F107 起，扫码线在画面右侧描出一张“放行包”轮廓，结构化字段像被扫描结果逐项填入；F124 卡片从扫描平面折叠转正，F132 到达完整可读状态。
- 卡片显示“Production Notice Workflow Standardization”、`20-40 min -> <1 min`、`Human final review`。视觉上强调信息放行与物料放行是同一个控制事件。
- 卡片入场特效为扫描线、字段逐项锁定、边缘一次绿色确认脉冲；禁止全屏粒子爆发、漂浮窗堆叠和长时间霓虹。
- F132 为第一磁吸点。画面构图保留左侧移动 AGV、中央外圈和右侧卡片，扫描门不得被卡片完全遮住。
- 热点：扫码头、放行灯和卡片均共享 `notice` 语义。鼠标靠近时，工业准星被吸向扫描点；点击卡片固定详情，再点击 CTA 进入案例或公开项目。
- 声画：扫码器短响、定位销轻碰、继电器吸合和 AGV 二次起步。磁吸停点只保留环境循环与 DOM 边缘流光，不反复触发扫码声。
- 出镜衔接：放行灯的绿色扫光沿外圈边缘向左运动，接到机械臂腕部状态灯，成为下一镜视觉接力。

### 03 - 机器人取料与节拍判断

**时间**：F151-F252，6.250-10.500 s  
**速度曲线**：0.76 -> 1.05 -> 0.82 m/s；摄影机沿 AGV 左侧做一个不超过 36 度的单向弧线，绝不绕回。  
**焦点**：70% `RING_HERO_01.Center` + 30% 机器人肩部包围盒中心；42-52 mm，f/5.6。

- F151 机器人已处于合理预备姿态，而不是从静止直立突然启动。腕部和三爪内撑夹具沿外圈轴线接近。
- F162 夹具进入内孔；F174 三个爪同步接触；F181 达到夹紧力；F184 AGV 托具解除支撑；F188 后机器人开始抬升。物料交接顺序不可颠倒。
- F166-F198 启用动作子弹时间，场景动作最低 0.34x、96 fps 采样；摄影机时间保持 1.0x。观众看到夹爪橡胶/金属接触、机器人关节负载回弹和外圈离座，但不会感到相机突然刹停。
- 机器人抬升时，背景中唯一一块机器人单元 HMI 显示正在运行的节拍仿真：工位块、缓存、利用率和流动零件都在动。它是全片唯一从真实屏幕展开的项目。
- F198 屏幕做一次曝光受控的局部刷新；一条投影线从 HMI 边缘连到外圈运动轨迹；F214 `Factory Takt Simulator` 卡片从屏幕平面向镜头方向推出 6 cm 的透视深度，再在 DOM 层转正；F228 完整可读。
- 卡片嵌入 2 秒的真实运行预览，不使用静态假曲线。卡片文字只说明瓶颈、等待、阻塞和缓存；详细指标留到湿磨高潮统一出现。
- F228 为第二磁吸点。摄影机已形成机器人、外圈、磨床入口的三角构图；HMI 在侧后方，卡片不得挡住夹爪和腕部。
- 热点：HMI 可“展开/收回”卡片；外圈热点显示当前工艺状态；机器人腕部热点只显示一条技术信息，不再弹第二张卡。
- 声画：伺服啸叫随关节速度变化，夹紧时有低沉机械触感，气路只在实际动作帧排气。节拍卡展开使用与 HMI 刷新同步的短数字脉冲。
- 出镜衔接：机器人转腕将外圈带向右侧磨床，摄影机只跟随外圈，不再回看 HMI。

### 04 - 跟随物料进入磨床并完成装夹

**时间**：F253-F342，10.500-14.250 s  
**速度曲线**：0.82 -> 1.42 -> 0.68 m/s；横向从 X=-0.30 连续移动到 X=3.15，Y 始终增加。  
**焦点**：从外圈中心平滑混合至工件主轴定位面；40 -> 32 mm，f/6.3。

- 磨床双层防护门在机器人到达前已经完成联锁释放并开始打开。机器人不能穿门，摄影机也不能穿过未打开的实体。
- 镜头与外圈近似同速并行 1.2 秒，让外圈在画面中的相对位置稳定，背景门框和机床外壳高速产生纵深视差。这是“一镜到底”的主要速度感来源。
- F287 外圈进入工件主轴定位空间；F310 端面贴近定位面；F318 工装夹紧；F324 夹爪卸载；F329 三爪收回；F337 机器人完全退出安全平面。
- 摄影机从开启的正面门净空进入内腔，不使用穿墙。门框在 F305-F318 近距离掠过镜头边缘，形成一次自然遮幅，但画面不得全黑，也不得借遮幅偷偷切镜。
- 本段不出现卡片。屏幕、铭牌、状态灯只服务空间真实感，让观众专注于物料从机器人到主轴的连续交接。
- 声画：机器人负载运动、工装贴合、液压/气动夹紧和安全门驱动。门框掠镜时音乐高频短暂收窄，为内部空间做听觉过渡。
- 出镜衔接：F337 机器人退出，F340 防护门在镜头身后关闭；镜头视线已经落到工件与砂轮轴线，下一动作无需转头寻找。

### 05 - 湿式磨削沟道，工艺高潮

**时间**：F343-F498，14.250-20.750 s  
**速度曲线**：0.68 -> 0.46 -> 0.62 m/s；这是最慢段，但摄影机仍持续向前。只做一次由总成到接触点的推近，不左右摇摆。  
**焦点**：工件中心 -> 沟道接触点 -> 工件中心；38 -> 85 -> 58 mm，f/7.1，接触点始终在中央安全区。

- F343-F360，机器人退出、门联锁成立、夹紧信号确认。只有这些条件满足后工件主轴和砂轮主轴才能启动。
- 工件外圈以约 180-240 rpm 绕水平轴旋转；小直径灰绿色 CBN 砂轮以约 10,000-12,000 rpm 反向形成切削速度。砂轮和工件轴线平行，砂轮先轴向进入内孔工作平面，再径向进给 10-14 mm 到内沟道。
- 旋转必须可读：外圈追溯点、油膜高光和甩液轨迹共同显示低速旋转；砂轮通过轮缘高光、轮毂标记和正确运动模糊显示高速，不使用清晰静止辐条。

卡片实现原则：

- 工厂渲染只提供真实物理画面、HMI 内容、投影锚点和遮挡数据；主要卡片使用 DOM/WebGL 叠层，保证文字清晰、链接可访问。

- 移动端热点最小 48 x 48 px，不依赖 hover，不显示自定义鼠标；首次点击展开，第二次点击 CTA。
- `prefers-reduced-motion` 下取消弹簧、投影线流动和指针吸附，改为 140 ms 淡入；内容和链接不得丢失。

## 8. 滚动、磁吸与播放逻辑

网页状态只有三种：`SCRUB`、`MAGNETIC_READ`、`SUMMARY`。

### SCRUB

- 单次标准滚轮 `deltaY=100 px` 只推进约 0.22 s，即 5-6 帧。
- 推荐映射：`deltaSeconds = clamp(deltaY * 0.0022, -0.32, 0.32)`；高分辨率触控板保持连续输入，不量化成整页跳转。
- 目标时间经过约 160-190 ms 的临界阻尼追随；不得直接把滚轮事件变成 0.5 秒以上跳跃。
- 正向和反向均可，但相机画面只按时间倒放，不另算一条反向路径。快速反向时禁用一次性声音事件，避免气阀、扫码声反复轰炸。

### MAGNETIC_READ

磁吸帧仅有 `F132 / F228 / F474 / F660`。身份卡不吸附，终点不吸附。

- 进入目标前后 10 帧窗口时，把剩余时间以 180 ms 阻尼拉向精确帧，不允许从 30 帧外突然跳过去。
- 到达后锁定媒体目标时间，但 DOM 卡片、准星、数字和边缘光可继续运动，避免整个网页像截图。
- 累计 28 px 同方向新输入后释放磁吸；释放时从当前帧继续，不额外跳帧。
- 同一个磁吸点在离开 18 帧前不得再次捕获，防止滚轮轻微抖动反复吸回。
- 自动播放/Replay 模式忽略磁吸，完整 38 秒连续播放。

### SUMMARY

- F904 后开始预加载和显示汇总；F912 后解除沉浸式滚动锁定。
- 正常页面滚动只能在汇总页开始。用户向上回滚时，先回到黑场 F912，再进入影片时间轴，不能直接跳回中段。

## 9. 摄影机与 Sequencer 实现

推荐层级：

`CAM_V8_PathRoot -> CAM_V8_Stabilizer -> CAM_V8_CineCamera`

- `PathRoot` 只承载连续空间位移，使用单一 Curve/Camera Rig Rail。
- `Stabilizer` 承载 2 度以内的 roll、微小呼吸和运动抑制，不负责主体追踪。
- `CineCamera` 承载焦段、光圈和对焦；焦段变化必须在 10 帧以上完成，禁止一帧跳变。
- Look-at 目标使用 `AIM_RING / AIM_SCAN / AIM_ROBOT / AIM_CHUCK / AIM_GRIND / AIM_INSPECT / AIM_DOOR` 七个 Empty/Actor。目标之间以 12-24 帧权重交叉，不直接切换约束。
- 相机速度曲线不得包含零斜率平台，F906 前始终正向移动。动作子弹时间只作用于 `SQ_Action_*` 子序列或 Blender 的独立 visual clock，不得重映射 Camera Action。
- 景深焦点跟随目标的低通版本，时间常数约 180 ms；机器人交接和磨削段不可出现焦点抽动。
- 机床入口、下游出口和终点门必须做相机碰撞扫掠测试。门框可近掠，但镜头近裁面不能切掉门体或穿过主轴壳体。

建议 Sequencer 分轨：

| 轨道 | 内容 |

| `SQ_RING_HERO_01` | 全部父级交接与旋转状态 |
| `SQ_ROBOT_Load` | 机器人关节、夹爪、气路、电缆包 |

## 10. 磨削流体、火星与材质实现要求

- 冷却液主体使用有体积厚度的 mesh ribbon/flipbook/流体缓存，近景加入速度驱动液滴；禁止只用透明圆柱或没有碰撞反应的粒子线。
- 喷嘴出口速度、接触点法线、轮缘切向速度和重力共同决定飞液方向。喷流击中工件后必须分叉、贴附、甩出并落入回液槽。
- Blender 可采用 Geometry Nodes + cached particles + shader flow；UE 可采用 Niagara mesh ribbons、GPU particles、distance-field collision 和局部 decal/wetness mask。二者都必须把接触点和排液槽设为真实碰撞/吸附区域。
- 机床内壁有湿润区、积液区、油污轻微残留和高压冲刷后的方向性痕迹，但不能做成脏旧废弃工厂。
- CBN 砂轮工作层为灰绿色陶瓷结合剂，只有近景可见细小随机磨粒和轻微粗糙度变化；磨粒不得放大成石块。
- 工件为磨削钢材，端面、外径和沟道有不同方向的加工纹理；沟道在磨削后高光更连续，但不变成镜面镀铬。
- 微火星只在有效接触帧生成，初速度沿切向，受到冷却液阻尼后快速熄灭；每个火星必须有起点、短轨迹和终止，不得漂浮。
- 最终渲染至少输出 Motion Vector、Z Depth、Cryptomatte/Object ID、Screen Matte、UI Anchor Matte 和 Clean Plate，供卡片遮挡、景深和网页合成验证。

## 11. 声画设计

独立电影母版可使用完整声音；网页滚动版默认静音，用户主动开启后由 Web Audio 读取进度触发分层声音。

| 声音层 | 范围 | 设计 |
| --- | --- | --- |
| Factory bed | 全片至 F900 | HVAC、远处设备、空间混响；随镜头进入机床改变频谱 |
| AGV | F001-F150、F703-F882 | 电机转速、轮胎、悬挂和提示音，音高跟随真实速度 |
| Robot | F151-F342 | 六轴伺服、制动释放、夹爪和气路，位置随 TCP 移动 |
| Grinding | F343-F498 | 主轴升速、冷却泵、接触窄带声、液体冲击、退刀衰减 |

| Door/black | F824-F912 | 门驱动、联锁、声场被暗前室吸收，最终自然衰减 |

网页声音规则：

- 环境和机械连续声使用可无缝循环的 stems，音量/滤波由时间区段驱动。
- 扫码、夹紧、接触、合格、开门等 one-shot 设置方向感知和 1.2 秒冷却时间；反向快速 scrub 不触发。
- 磁吸停住后只维持环境循环，不重复播放动作瞬态。
- 声音开关必须明确可见并记忆用户选择；无用户手势时不尝试自动播放。

## 12. 桌面与移动安全构图

- 桌面 16:9 以物料运动方向留出前方空间，卡片通常落在相反侧。不得为了卡片把真实主体推到画面边缘。

- 磨削指标卡移动版放在下三分之一，但与接触点保持至少 12 vh 净距；必要时按顺序显示三项指标，而不是缩小到不可读。

- 所有卡片、热点、进度条和联系方式不得产生横向溢出。
